# Community Center v1.0

Java와 Spring Boot를 활용한 주민센터 관리 웹 애플리케이션입니다.

## 프로젝트 소개

Spring Boot 기반의 REST API와 HTML, CSS, JavaScript를 활용하여 주민 정보를 관리하는 학습용 프로젝트입니다.

## 사용 기술

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- HTML / CSS / JavaScript
- Maven

## 주요 기능

- 주민 정보 등록
- 주민 목록 및 상세 조회
- 주민 정보 수정 및 삭제
- 이름으로 주민 검색
- 주민 목록 정렬 및 페이지네이션
- 관리자용 주민 관리 페이지
- 주민센터 소개 홈페이지

## 프로젝트 목적

Java 백엔드와 웹 프론트엔드의 연동을 학습하고, REST API 및 데이터베이스를 활용한 웹 애플리케이션 개발 과정을 익히기 위해 제작했습니다.

본 프로젝트는 학습 및 포트폴리오 목적으로 제작된 v1.0 버전입니다.
